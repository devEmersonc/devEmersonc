<h2>Backend</h2>

<ul>
  <li><strong>Lenguaje:</strong> Java</li>
  <li><strong>Frameworks:</strong> Spring Boot, Spring MVC, Spring Security</li>
  <li><strong>Persistencia:</strong> Spring Data JPA, Hibernate</li>
  <li><strong>Seguridad:</strong> JWT, autenticación, autorización y control por roles</li>
  <li><strong>Bases de Datos:</strong> MySQL</li>
  <li><strong>APIs:</strong> Diseño y desarrollo de APIs REST</li>
  <li><strong>Testing:</strong> JUnit, Mockito</li>
</ul>

<h2>Herramientas</h2>

<ul>
  <li><strong>Build:</strong> Maven</li>
  <li><strong>Control de versiones:</strong> Git, GitHub</li>
  <li><strong>Testing de APIs:</strong> Postman</li>
  <li><strong>Base de datos:</strong> DBeaver</li>
  <li><strong>IDE:</strong> IntelliJ IDEA</li>
</ul>

<hr/>

<h2>Enfoque</h2>

<ul>
  <li>Desarrollo de APIs REST mantenibles y estructuradas</li>
  <li>Aplicación de arquitectura por capas y principios de POO</li>
  <li>Implementación de autenticación y autorización con Spring Security y JWT</li>
  <li>Persistencia de datos mediante JPA e Hibernate</li>
  <li>Desarrollo de pruebas unitarias con JUnit y Mockito</li>
  <li>Diseño de lógica de negocio orientada a aplicaciones empresariales</li>
</ul>
